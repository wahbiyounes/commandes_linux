Guide Complet des Commandes Git & GitHub

1. Configuration Git

Commande Description
git config --global user.name "Younes" Définir le nom utilisateur Git.
git config --global user.email "email@gmail.com" Définir l’adresse email Git.
git config --list Afficher la configuration actuelle.

2. Initialiser un Projet Git

Commande Description
git init Initialiser Git dans le dossier du projet.
git status Afficher l’état des fichiers.

3. Ajouter les Fichiers

Commande Description
git add . Ajouter tous les fichiers.
git add nom_fichier Ajouter un seul fichier.

4. Faire un Commit

Commande Description
git commit -m "Premier commit" Créer une sauvegarde avec message.
git log Afficher l’historique des commits.
git diff Afficher les modifications.

5. Connecter le Projet à GitHub

Commande Description
git remote add origin https://github.com/USERNAME/PROJET.git Connecter le projet local avec GitHub.
git branch -M main Créer ou renommer la branche principale en main.
git push -u origin main Envoyer le projet vers GitHub.

6. Mettre à Jour le Projet

Commande Description
git pull Récupérer les dernières modifications.
git push Envoyer les nouvelles modifications.

7. Gestion des Branches

Commande Description
git branch Afficher les branches.
git branch nouvelle_branche Créer une branche.
git checkout nouvelle_branche Changer de branche.
git checkout -b nouvelle_branche Créer et changer de branche.
git merge nom_branche Fusionner une branche.

8. Restaurer ou Annuler

Commande Description
git restore nom_fichier Annuler les modifications d’un fichier.

9. Copier un Projet GitHub

Commande Description
git clone URL Copier un projet GitHub vers le PC.


Workflow rapide :

git add .

git commit -m "message"

git push


Les Commandes Git Essentielles

Commande Description
git init Initialiser Git dans un projet.
git status Afficher l’état des fichiers modifiés.
git add . Ajouter tous les fichiers avant le commit.
git add nom_fichier Ajouter un seul fichier.
git commit -m "message" Créer une sauvegarde avec un message.
git log Afficher l’historique des commits.
git diff Afficher les modifications avant commit.
git restore nom_fichier Annuler les modifications d’un fichier.
git branch Afficher les branches du projet.
git branch nom_branche Créer une nouvelle branche.
git checkout nom_branche Changer de branche.
git checkout -b nom_branche Créer et changer de branche directement.
git merge nom_branche Fusionner une branche avec la branche actuelle.
git clone URL Copier un projet GitHub vers le PC.
git pull Récupérer les dernières modifications du serveur.
git push Envoyer les modifications vers GitHub.
git remote add origin URL Connecter le projet local avec GitHub.
git config --list Afficher la configuration Git.
